# TaskFlow — Simple Task Tracker

TaskFlow is a responsive to-do list app built with plain HTML, CSS, and JavaScript. It is a beginner-friendly project for practicing GitHub basics.

## Features

- Add and delete tasks
- Mark tasks as completed or active
- Filter by all, in-progress, and completed tasks
- Automatically save tasks in your browser using `localStorage`
- Responsive layout for desktop and mobile
- Accessible labels and keyboard focus styles
- No frameworks, build tools, API keys, or installation required

## Run it locally

1. Open or download this repository.
2. Open `index.html` in a modern browser.
3. Add a task and try the filters.

For local development, you can use the Live Server extension in Visual Studio Code.

## Project files

- `index.html` — page structure
- `style.css` — layout, colors, and responsive styling
- `script.js` — task management and browser storage

## Data and privacy

Tasks are stored in the browser's local storage on the device where you use the app. They are not sent to a server. Clearing browser site data may remove saved tasks.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under the build/deployment source, select **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then save.
5. Wait for GitHub Pages to publish the site. The Pages section will show its URL.
